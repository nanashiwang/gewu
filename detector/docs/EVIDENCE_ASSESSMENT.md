# 检测结论的证据边界

报告将本次接口可用性、已测能力和模型身份证据分开描述。模型目录仅提供候选名称，不能证明中转站有该模型的权限或实际使用了该模型。

- 原始 `total_score` 与 `verdict` 保留既有加权算法，方便复现与兼容旧报告；对外展示或消费质量分前必须检查 `assessment.score_usable`。
- 没有核心探针、发生执行错误、运行级错误或报告字段无效时，显示“暂不计分”。错误与跳过分别列出，不当作模型造假证据。
- 新生成的 JSON 内含 `assessment`，历史 JSON 在 HTTP 读取和渲染时重新评估；无需修改历史原始报告。CLI、HTML、SEO 与 JPG 使用同一个评估函数。
- Anthropic 的原始签名回放和篡改负向对照均通过时，说明本次协议对照通过。不声称完成本地公钥验签，也不据此确定具体模型版本。
- 模型自述、公司知识题、响应 ID、模型名、复制的响应字段、输出风格与高分，均不能单独证明模型身份。自述出现其他品牌只触发复核提示。
- 公共榜单继续要求来源与审核元数据，且只消费完整、可计分的报告。经审核且完成核心请求的部分观测可以在监测页显示为未完成，但不显示分数，不参与排名。
- 站点桥接器遇到无效或不完整报告时保留脱敏证据和报告链接，将任务记为未完成，不更新站点质量分。

模型目录的唯一编辑入口是 `src/relay_detector/data/model_catalog.json`。Python 包、公共检测表单与账号表单共用它；更新模型仍需按官方来源核对，日常审计工作流不会自动把网页变化写入目录。

执行队列仍是单进程；任务元数据和脱敏的已完成证据会原子保存，重启后标记中断并生成不计分报告，不保存临时 API Key、不自动重试。取消权限由提交者的 HttpOnly Cookie 或内部服务令牌验证，分享链接不授予取消权限。等待页按真实探针事件显示进度，状态接口仅对可计分报告返回分数；错误项目不计入有效结果数。超时保留已完成探针结果并清理未完成任务。

站点页面仅在有活动任务且页面可见时每 15 秒刷新，10 分钟后停止自动刷新；任务结果仍由服务端定时同步。刷新页面不会启动新检测。

中文 JPG 需要中文字体。部署可将 Ubuntu `fonts-noto-cjk` 包中的 `NotoSansCJK-Regular.ttc`、`NotoSansCJK-Bold.ttc` 与许可证复制到检测站根目录 `report_fonts/`；渲染器优先读取该目录，无需修改系统字体。2026-10-12 核验包版本为 `1:20230817+repack1-3`，包 SHA-256 为 `7d64b985f6fe128c99eae5610d5c047338e572bdcfb2bb09736be01b824a7f6c`。字体属于部署资源，应保留许可证且不提交本机字体。
