# 按模型比较平台线路

## 能力与决策

模型价格页和首页简表共用 `_pricing_table.html`，此前模型名和供应商数只有文本，用户无法继续比较。已有质量榜按站点汇总格物审核证据，模型观测按采样记录展示，均没有第三方平台的线路和报价明细。

本次扩展现有公开价格源 Oken 的 `/suppliers` 只读接口，新增 `/leaderboard/models/compare?model=...&billing=...`。模型名称和供应商数量都链接到此页，保留当前计费方式；不同平台的同名分组按源线路 ID 区分。使用已有 `/leaderboard` 代理前缀，避免新增顶层 URL 再次落入 Next 账号平台。

备选方案：仅跳去 Oken 可快速查阅，但会中断格物浏览流程；把第三方评级写入格物榜单会混淆证据和采样口径，因此不采用。此次选择独立展示第三方比较结果，原始信息链接可复核，不改变格物检测、评分和准入规则。

## 页面与数据边界

- 模型必须匹配现有市场目录中的名称及计费方式；未知返回 404，参数越界返回 422，来源不可用返回 503 和可读提示。
- 固定 HTTPS API 地址，参数编码，不跟随跳转，不使用个人 Cookie、Key 或报告；不调用试用、付费探测或刷新响应速度接口。
- 请求声明每页 200 条，但来源可能忽略分页参数；每次最多接受 1000 条 / 3 MiB，整体抓取限时 12 秒。源声明的总量超过当前返回数量时标注部分结果，筛选和排序只针对已展示条目。
- 32 个模型/计费组合的进程内缓存，成功 5 分钟、失败 30 秒；没有后台轮询，失效数据不冒充最新。
- 仅解析公开展示所需字段。模板转义外部文本，不渲染上游 HTML，不接受上游任意跳转地址。原始信息链接由固定 Oken 域名和编码后的模型名构造。
- S/A/B/C 使用上游 `sort_level`，官方基准独立展示；缺少评级为“暂无评级”。平台名称、分组、评级和监测不推断为整个站点的格物评分。
- 按量的供应商输入/输出/缓存价已经是人民币每百万 Tokens，不额外乘除。按次独立显示；按尺寸、时长不强行转换成 Token 单位，显示依规格计费并保留原始信息入口。多值价格不擅自取最低值。
- 稳定性须同时有采样时间和来源说明，缺失时显示未知；不把无数据当成 0% 正常率。保留监测说明和来源时间原文，不假定来源采样时区。
- 搜索、平台、评级与排序在浏览器本地完成，不额外抓取。可展开线路查看充值条件、接口类型、监测口径与采样时间。

## 验证与部署

单元及路由测试：`PYTHONPATH=detector python -m pytest -q detector/tests/test_model_routes.py detector/tests/test_public_rankings.py`。

实际验证示例：价格页点击 `gpt-6.1-terra`，进入比较页，匿名公开接口返回 21 家平台、70 条线路（数量会随来源变化）；确认组合筛选、价格排序、空结果与详情展开。

发布后从公网点击首页和价格页的模型入口，核对模型/计费参数、来源异常页面及移动端横向表格。现有生产 `location ^~ /leaderboard` 已转发检测容器，无需为本功能新增 Nginx 顶层规则。源接口无版本契约，结构变更会停止展示并报不可用，需维护适配器。

## 筛选与并发读取补充

报价下方直接展示源站充值条件。筛选通过 q/grade/shop/sort 查询参数保存，保留 model/billing；刷新、分享和历史导航可恢复，未知值回到默认，可一键重置。手机样式固定评级和平台列。

同一事件循环内，同模型与计费方式的并发请求共用一次读取，最多同时读取 8 个组合。等待者取消不影响主请求；主请求取消后，其他等待者收到不可用结果，并释放槽位。不创建脱离请求的后台任务。

交互回归见 detector/tests/model_comparison.test.mjs，覆盖网址恢复、组合筛选、空结果重置、历史导航和缺失值排序。Python 测试覆盖请求去重和取消清理。

初版已验证浏览器跳转及移动端横向表格；后续布局、分页和固定列已完成离线交互回归，仍需真实浏览器视觉验收。


## 分页与详情行

2026-11-02 实测同一模型的 page=1/2、page_size=2，均返回相同的 70 条线路；当前不能将公开接口视为可依赖的服务端分页。仅对已读取的结果进行站内分页，每页 25 条，先筛选排序再分页。超过 1000 条或 3 MiB 返回不可用；来源 total 大于已读取条数仍标为部分结果，不伪称全量。

页码通过 page 查询参数保留，切换筛选或排序后回到第一页，越界页码限制在有效范围。评级按钮的数量统计符合当前搜索、平台和数据完整度开关的线路，不受选中评级和分页影响。

线路详情改为独立表格行，由 aria-controls/aria-expanded 关联对应线路；排序后详情仍紧随所属线路，过滤或翻页时同时隐藏，回到该行保留展开状态。详情不再挤宽最后一列。无 JavaScript 时展示完整已读取列表并提示筛选/分页/详情需要脚本。

## 数据完整度筛选与评级计数

新增“仅看有评级”（S/A/B/C，不含官方基准）和“仅看有稳定性数据”（包括有效的 0%）开关，随 rated=1/monitored=1 查询参数保存，重置时清除。开关只按公开数据是否存在筛选，不承诺数据新鲜度，也不代表站点获得推荐。

评级按钮的数量现改为跟随搜索、平台、两个开关的条件，统计发生在选定评级和分页之前。选择某评级不会将其他评级数量清零，便于在同一平台范围切换。无匹配时保留选中评级并显示空结果，不静默放宽条件。
