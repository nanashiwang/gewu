PUBLIC INTEREST GOVERNANCE

榜单治理与申诉

用户自测报告可以分享，但不会自动影响公共排名。榜单只使用来源明确、完成核心探针且经过审核的证据。

什么证据可以进入榜单

  • 格物运营方使用受控配置执行的定时监测；
  • 运营方人工复核并批准的完整检测；
  • 完成域名所有权验证后，由站点所有者申请复测并经审核的报告。

运行错误、鉴权失败、核心探针未完成、来源或审核信息缺失的报告一律不计分。旧报告不会因历史上曾公开而自动获得资格。

如何申请复测或申诉

  1. 准备涉及的域名、榜单页面和报告编号；不要提交 API Key。
  2. 如主张站点所有权，请准备 DNS TXT 或 /.well-known/ 文件验证。
  3. 在项目公开 Issue 中提交复测申请：创建申诉或复测 Issue ↗。
  4. 运营方复核后重新检测；证据无效时立即撤下，成立时以新证据更新榜单。

申诉、复测和撤下不收费，不因购买、赞助或商业关系改变结论。

公开审计字段

每条格物榜单证据公开检测时间、证据来源、审核状态、检测器版本和基线版本，并保留可进入的字段级报告。
