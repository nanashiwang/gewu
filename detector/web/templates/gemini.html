OpenAI 兼容协议

关键能力

探测 tool 调用、JSON schema strict 模式、流式与非流式响应一致性,识别能力缺失或参数没有透传的中转层。

用量字段

按所选接口检查用量字段与完成状态。缺失用量会标注；显示值是上游声明，不代表实际扣费。

常见问题(精选)

为什么 Gemini API 中转站经常 model_not_found?

可能是接口未代理该型号、当前 Key 无权限、模型 ID 不一致或模型已下架。 候选目录不保证调用成功。原生接口直接以首个检测请求检查可用性，不额外付费预检，也不会自动替换模型。

Gemini 检测为什么可能得到空文本?

带思考的模型可能把输出额度用于推理，输出预算过小会导致正文为空。 应结合 finish_reason、usage 和官方能力说明判断，不能仅凭空文本认定模型有问题。
