# Changelog

## 2026-10-16：检测服务容器发布与受限清理

- 全量 CI 通过后构建并检查检测镜像，发布提交版本对应的 GHCR digest 与 GitHub Release 归档。
- 服务器按版本、SHA256 和镜像 ID 校验；隔离冒烟通过后迁移 Web 检测服务，保留原安装及自动回滚。
- 基线目录支持 `GEWU_BASELINES_DIR`，容器只读挂载服务器已有基线，密钥和用户报告不进入镜像。
- 清理仅处理超过 30 天的已识别部署暂存目录，保留最近两份并记录清单；不执行全局 Docker 清理。

All notable changes to **格物** are documented here.
This project adheres to [Semantic Versioning](https://semver.org/) and the
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

公开站点地址由部署方通过 `GEWU_SITE_URL` 配置。

## [Unreleased]

### 2026-10-16 · 采样取消与异常证据校验

- 官方采样在等待响应或读取响应期间取消后，记录停止原因并禁止后续请求；保留取消语义，错误响应关闭前即锁定停止状态。
- 统一报告与基线的数值校验，拒绝超大整数、非有限数值和加权运算溢出，损坏样本不会使库存或报告对照崩溃，也不会获得有效评分。
- 正常报告沿用原加权公式，历史文件保持原样；补充取消清理、异常基线和有效小数权重的离线回归测试。

### 2026-10-15 · 官方采样审核与逐项对照

- 新增默认离线预览的 `baseline-collect`，实际执行使用专用官方凭据，固定端点与模型，并对每次发送预留请求、输出和输入字节预算；禁用额外参考采样旁路。
- 新增哈希确认与独立来源复核的 `baseline-approve`，按协议、接口、模型和采样版本存档，不覆盖历史文件；错误、超限、过期或不完整样本拒绝发布。
- 报告页与 CLI 使用共享的严格基线选择，展示同范围计分项目的官方/本次/差值；缺样本明确提示，不重写历史报告或放宽榜单准入。
- 补充 DeepSeek 官方状态和 Artificial Analysis 入口，外部通告保持独立于检测证据；本轮不采集付费样本，不新增巡检定时器。

### 2026-10-14 · 外部状态参考与检测范围

- 引用 AI Status Hub 的官方故障通告聚合，保留固定官方来源、采样时间和覆盖边界；缺失、过期、未来时间、重复记录或读取失败均显示未知，不参与评分。
- `/leaderboard/sources` 集中展示九家厂商的覆盖情况、Oken / ModelUptime 外部入口及基线库存；说明 OpenRouter 路径与官方直连、Vertex 与 AI Studio 的区别。
- 检测前按实际 runner 展示模型、接口、深度对应的探针与观察项，不读取或转发用户 Key、接口地址；切换后防止旧响应覆盖新选择。
- 基线新增独立的文件哈希与官方端点审核清单，提供离线 `baseline-audit`；历史样本不补写元数据，不自动采集付费样本。
- 修正模型目录、FAQ、首页、报告和 JPG 的范围说明；移除采集脚本默认旧模型扫描，必须显式指定采样型号。

### 2026-10-12 · 检测判定校准

- 新增证据评分 v2：模型自述、行为风格和知识问答只作观察，不参与总分；输出长度波动及签名长短不再单独扣分。
- 保留签名原始回放与篡改对照，检查每次响应的型号字段；字段一致不宣称证明模型身份。
- 基线比较核对模型、协议与接口、深度、评分和探针版本、30 天内采样、有效证据及实际计分覆盖；不满足条件时不输出降级结论。
- 历史报告保留原分，榜单与趋势隔离评分和探针版本；当前报告缺少可比基线时不进入公共评分榜单。
- HTML、JPG、CLI 与账号端统一标注观察项和评分版本；仅观察、全部跳过、伪造总分或未知规则的报告不计分。
- 本轮验证使用合成上游，未执行付费官方基线采样；旧基线文件保持不变。

### 2026-10-12 · Gemini 原生接口与任务一致性

- 新增 Interactions 和 generateContent 原生能力检测，显式选择接口，不重试、不回退，不额外发起付费预检。
- 原生快速 / 标准 / 完整最多 2 / 3 / 5 次请求，覆盖随机文本、流式完整性、JSON Schema 和本地函数往返；关闭上游存储，签名历史仅留在内存。
- 检测页、HTML/JPG 报告和说明统一标注接口与覆盖范围；旧兼容检测不再宣称使用原生请求。原生分数不混入现有公共榜单。
- 账号手动与定时任务保存接口快照，报告接口不符拒绝计分；趋势按相同接口、模型、深度分组，变更配置不被旧任务成绩覆盖。
- 新增两列可空接口字段，历史任务不回填、不改用新接口；迁移及回退在临时数据库验证。

### 2026-10-12 · Responses 能力检测

- 新增网页与 CLI 的 Responses 检测选项，覆盖基础回复、流式完整性、严格 JSON 与本地模拟工具调用往返。
- 快速/标准/完整档最多 2/3/5 次请求，关闭存储、自动重试、额外预检及接口切换，遇到核心失败及时停止。
- 报告与 JPG 标明接口和实际能力覆盖；不完整证据不计分，Usage 缺失明确提示，Responses 分数不混入原有公共榜单。
- 增加合成上游对抗测试，验证错误正文、流截断、工具参数与回传、请求预算、取消清理及旧接口兼容。

### 2026-10-12 · 运营监测健康

- 修复监测探针鉴权失败仍以成功退出的问题；已完成的低分检测与无效检测分开处理。
- 定时检测先执行基础探针，鉴权失败后停止剩余任务与补充请求，连续失败进入持久冷却。
- 增加管理员监测健康页和公开采样汇总，展示最近有效检测与连续失败；私有详情默认拒绝匿名访问。
- 复用历史运营报告重建状态，不修改原报告、榜单准入规则或服务器定时策略。

### 2026-10-11 · 厂商与模型目录

- 厂商选择扩展到九家，目录统一管理，显示官方来源、复核日期和受限产品说明。
- 补充当前 Claude、GPT、Gemini 与六家兼容厂商的文本模型；支持从接口读取未收录型号，切换厂商必须重新选型号。
- 按官方能力跳过不适用探针，修复自定义 API 根路径、推理预算、参数与接口差异；兼容模型先提供基础检测，不混入公共榜单。
- 增加每日官方页面 ID 巡检和 30 天复核期限。发现变更后需审核更新，不自动导入未知能力。

### 2026-10-11 · 检测证据与模型观测

- 当前排名与历史参考分离，所有来源统一应用 30 天时效；实测分数不混入过期样本。
- 禁止固定快照绕过证据审核自称格物实测，拒绝无时区、未来时间和不安全地址。
- 新增模型观测、UTC 七天样本状态和分组报告入口；未知线路和无数据明确标注，不推算可用率。
- 首页突出检测用途与费用边界，价格折叠为辅助信息；移除榜单推广位，报告强化证据解释。
- 保持检测站独立运行，不自动开启收费检测。

## [0.1.0] - 2026-05-10

### Added
- 三协议检测:Anthropic Messages API、OpenAI Chat Completions、Gemini OpenAI 兼容协议
- Claude thinking signature 字段检测(现已由 Unreleased 的原始/篡改回放取代)
- OpenAI usage 字段后端指纹识别(检测 `claude_cache_creation_*` 异源痕迹的「换芯」中转站)
- Gemini 3 thinking-by-default 适配
- 三层 needle-in-haystack 长上下文探针(32k → 1M tokens),抓「宣传 1M 实际只给 200k」式欺诈
- 加权评分 + critical issue 一票否决(单项 critical 把 verdict 上限锁在 marginal)
- 三档运行模式:quick / standard / full(费用取决于模型、实际输出和中转站定价)
- Web 服务:FastAPI + 异步任务队列、IP 限速、报告 JPG 卡片生成
- 中转站红黑榜:按域名聚合公开报告,贝叶斯排序防 1-sample 刷分
- 可分享链接 `/r/{id}` 与社交分享图片 `/r/{id}.jpg`
- CLI 工具 `gewu`:`detect` / `compare` / `ping` 三个子命令
- 官方基线收集脚本 `bench.sh`(Opus 4.7 / Sonnet 4.6 / Haiku 4.5 / Opus 4.6)

### Privacy
- 原始 API key 仅用于调用用户配置的目标中转站,不写报告、不持久化到磁盘
- 报告中 key 脱敏为 `sk-y7xU••••••0h` 格式
- 无注册;统计脚本仅在部署方显式配置 analytics ID 时加载
